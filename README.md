# Basic-Program Repository

Welcome to the **Basic-Program** repository! This collection showcases fundamental Python programs developed by [Ajeet Yadav](https://github.com/ajya97), a B.Tech student specializing in Artificial Intelligence and Data Science. The repository serves as a learning resource for beginners aiming to grasp basic programming concepts through practical examples.

---

## 📁 Repository Contents

The repository includes the following Python programs:

- **Cafe Management System (`Cafe Management.py`)**: Simulates a simple cafe order management system, allowing users to place orders, calculate totals, and generate bills.

- **Contact Directory (`Contact Directory.py`)**: A basic contact management application enabling users to add, search, and manage contact information.

- **Guesser Number Game (`Guesser Number Game.py`)**: An interactive game where the user attempts to guess a randomly generated number within a specified range.
